================================================================================
1. GOAL
================================================================================
Build a low-compute, low-latency collision-anticipation model for a wearable that
helps a blind person avoid collision-worthy obstacles (cars, people, cyclists,
potholes) and ignore clutter (leaves, texture).

There is NO object detector, NO tracker, NO optical flow, NO TTC, NO YOLO.

The wearable model (student) must:
  - take 3 cheap RGB frames
  - predict a 5x5 threat heatmap 1 second into the future
  - turn that into LEFT / CENTER / RIGHT + SAFE / CAUTION / STOP
  - run in <10 ms CPU (ideally <5 ms)

Training uses a teacher/student JEPA setup. The teacher (frozen V-JEPA-2) runs
OFFLINE only, never on-device, never during student training live.

4. REPRESENTATIONS / SHAPES (locked)

Sample t           : student t in [10, 119]; teacher needs t >= 14

================================================================================
5. ARCHITECTURE
================================================================================

5.1 Stage-0 baseline (no JEPA)  — models/baseline.py
  Shared TinyCNN on 3 frames -> F1,F2,F3 at 5x5
  D1 = F3-F2, D2 = F3-F1
  concat [F3,D1,D2] -> 1x1 conv head -> sigmoid -> Hhat+
  ~93k params. Proves whether RGB+diffs can beat copy. They did NOT.

5.2 TinyCNN  — models/tiny_cnn.py
  Depthwise-separable CNN, width=32, feat_channels=128
  stem stride2, 4 DW-separable blocks (3 of them stride 2)
  Pool to 5x5 via bilinear resize to 10x10 then 2x2 avg pool
  (NOT AdaptiveAvgPool2d: ONNX export failed on 8->5)

5.3 Teacher (offline only)  — models/teacher.py
  Frozen HF backbone: facebook/vjepa2-vitl-fpc64-256  (~0.3B, fp16)
  tokens -> reshape temporal/spatial grid -> mean over time
  -> 1x1 reduce (hidden->64) -> AdaptiveAvgPool2d(5) -> bottleneck to 16 ch
  HeatmapDecoder: 3x 1x1 conv, sigmoid -> H
  ONLY adapter+decoder trained (~72k params). Backbone frozen.
  Stage A objective: reconstruct CURRENT heatmap H_t from clip ending at t.
  Checkpoint: e:\btp\collision_jepa\checkpoints\teacher.pt
    best saved epoch=14
    val (CURRENT H): HT-recall 0.898, STOP-F1 0.848, MSE 0.031
    decoder(Z+) vs future H+ MSE = 0.031  -> Z IS a good future target if used right
  Z is UNNORMALIZED. Observed range about [-60, +60], std ~5.
  Training was stopped early (OOM at epoch 10, resumed, then user stopped at epoch 15).
  Resume supported: python scripts/03_train_teacher.py --micro-batch 1 --resume
  Use micro-batch 1 on this 4 GB GPU.

5.4 Student (wearable)  — models/student.py  ~591,777 params
  Shared TinyCNN -> F1,F2,F3, D1=F3-F2, D2=F3-F1
  CollisionEncoder([F3,D1,D2]) -> Z_t
  ResidualPredictor: Zhat+ = Z_t + P(Z_t, D1, D2)
  Frozen teacher HeatmapDecoder: Zhat+ -> Hhat+
  Deployment path: Student.predict_future_heatmap(frames) -> [B,5,5]
  Checkpoint: e:\btp\collision_jepa\checkpoints\student.pt  (best epoch=2)

5.5 Warning head (no NN)  — warning.py
  Near-weighted max over column groups:
    LEFT cols 0-1, CENTER col 2, RIGHT cols 3-4
    row_weights [0.4, 0.6, 0.8, 1.0, 1.0]
  Severity: score >= 0.75 STOP, >= 0.45 CAUTION, else SAFE
  HitLatch hysteresis: confirm_frames=3, release_frames=5
  dir-acc = direction accuracy ONLY on frames where GT severity >= CAUTION

================================================================================
6. LOSSES
================================================================================
L = L_H + lambda * L_JEPA     lambda=0.1 in configs/default.yaml

L_H    = weighted_focal_mse(Hhat+, H_future)
         weight = 1 + focal_weight * target^gamma   (focal_weight=1, gamma=2)
L_JEPA = MSE(Zhat+, Z+) + (1 - cosine_sim over channel dim).mean()

Intended: heatmap first. ACTUAL (measured on val):
  L_H ≈ 0.14
  L_JEPA ≈ 18.1   because Z is huge
  0.1 * L_JEPA ≈ 1.81
  => ~93% of the loss is latent matching, not heatmap.
  This is a primary reason the student is bad.

================================================================================
9. DIAGNOSED REASONS THE STUDENT IS POOR (do not ignore)
================================================================================
1) Copy / mean-map ceiling.
   H(t+1s) ≈ H(t) on most cells. Predicting the average 5x5 already matches copy MSE.
   Copy is privileged (uses true H_t). Student only sees 128x128 RGB.
   Must win on the ~24% of cells / 27% of danger frames that actually change.

2) Student collapsed to the corridor prior.
   Mean pred is basically the average walking-corridor heatmap, not motion.

3) L_JEPA drowns L_H.
   Z ∈ [-60, 60], no LayerNorm/tanh. lambda=0.1 is not small enough.
   ~93% of the training loss is matching Z, not H.

4) Horizontal-flip bug.
   ClipAugmentor flips RGB + H with p=0.5, then StudentDataset attaches UNFLIPPED
   teacher Z. On half of train batches L_H and L_JEPA contradict each other.
   Code: collision_jepa/data/dataset.py StudentDataset.__getitem__
         collision_jepa/data/augment.py

5) Best checkpoint is epoch 2; training never recovered (conflicting losses).

6) Teacher target itself is NOT the problem.
   decoder(Z+) vs H+ MSE=0.031. Distillation can work if Z is normalized,
   flipped with the image, and L_H dominates.

Secondary:
  - 128x128 hides small/far hazards
  - student never sees H_t, so it cannot do "copy then residual" in heatmap space
  - near-row MSE is highest (0.155), where labels change most

Suggested fix order (not yet implemented):
  A. Normalize Z (per-channel or LayerNorm / tanh) before L_JEPA and caching
  B. Flip Z left-right whenever frames/H are flipped
  C. Make L_H dominate (lower lambda, or train heatmap-only first, then JEPA)
  D. Keep best-by-HT-recall+STOP-F1; consider early stop / lower LR
  E. Optionally predict residual in H-space too: Hhat+ = H_now_hat + ...
  F. Re-render overlays after a real student checkpoint
