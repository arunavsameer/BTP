MODEL TRIAL 3 — DETAILED FILE GUIDE
===================================

This folder trains a "teacher" model for wearable collision anticipation.
The teacher watches 3 seconds of RGB video and predicts a 5x5 danger map
at four times: NOW, 1 second later, 1.5 seconds later, and 2 seconds later.

It does NOT train a small student / TinyCNN. That is out of scope.

How to use this document:
  1. Read PART 1 (the story of one sample) if you are new.
  2. Read PART 2 (run order) before you launch scripts.
  3. Use PART 3 onward as a dictionary: open a file, find its section.


================================================================
PART 1. THE STORY OF ONE SAMPLE (simple)
================================================================

Dataset clip example:

  blender_sim/datasets/groups15_n400_s67_n400/
    sample_0000_jaywalker / collision / bg_00 /
      preview.mp4
      episode.json
      spatial_annotations/spatial_annotations.json
      spatial_overlay.mp4          <-- NEVER used as model input
      annotations/annotations.json <-- extra labels, not required

Video facts (from config + episode.json):
  1920 x 1080 RGB, 30 frames per second, 450 frames (15 seconds).
  Heatmap grid: 5 rows x 5 columns.
    row 0 = far / top of the image
    row 4 = near / feet
    col 0 = left
    col 4 = right
  Cell values are 0.0 (safe) to 1.0 (maximum threat).

Same sample also has:
  collision / bg_01     same hit, different street look
  miss_left / bg_00     same street, pedestrian misses instead of hitting
  miss_left / bg_01

Until frame 365 (the FORK, 12.15 seconds), collision and miss videos
look the same. After 365 they split.

What the model is asked, for a chosen time t (example t = 330):

  INPUT  = 16 RGB frames ending at t, 200 ms apart:
           frames 240, 246, 252, ... 324, 330
           That is 3 seconds of history. Nothing after t is shown.

  OUTPUT = four 5x5 maps:
           now  = heatmap at frame 330
           1s   = heatmap at frame 360
           1.5s = heatmap at frame 375
           2s   = heatmap at frame 390

Special rule (ambiguous_policy = mean_target, current default):
  If t is still BEFORE the fork, the past looks the same for collision
  and miss. If a FUTURE heatmap has already split (example: 2s = frame
  390 is after 365), we do NOT skip that loss. We put the cell-wise
  AVERAGE of collision and miss into that future target for both clips,
  then train on it.

  After the fork (t >= 365), each clip keeps its own future heatmap.

PART 2. HOW YOU RUN THE PROJECT
================================================================

Typical order:

  python scripts/00_inspect_dataset.py
  python scripts/01_build_manifest.py
  python scripts/02_prepare_cache.py
  python scripts/03_smoke_test.py
  python scripts/04_train_teacher.py --phase frozen
  python scripts/04_train_teacher.py --phase lora
      (or --phase both)
  python scripts/05_evaluate_teacher.py --split val
  python scripts/05_evaluate_teacher.py --split test
  python scripts/06_render_heatmap_overlays.py
  python scripts/07_profile_pipeline.py     (optional timing)

  python tests/run_tests.py                 (unit tests)

Python package root:  collision_jepa3/
Settings file:        configs/default.yaml
Workspace parent:     /home/.../BTP  (dataset lives under blender_sim/)


WHO CALLS WHOM (high level)

  scripts/04_train_teacher.py
      Config.load
      load_manifest + load_splits
      TeacherDataset  (data/dataset.py)
          sampling, pairing, heatmaps, cache, preprocessing, video_reader
      CollisionTeacher3  (models/teacher.py)
          vjepa_backbone -> spatial_adapter -> residual_predictor
          -> heatmap_decoder
      TeacherTrainer  (training/trainer.py)
          TeacherLoss (losses/composite.py)
          PairBuffer + background_consistency
          optimizer, checkpoint, early_stopping, evaluator


SHAPES YOU WILL SEE EVERYWHERE

  raw video frame          [1080, 1920, 3] uint8 RGB
  letterboxed frame        [256, 256, 3] uint8
                           content is 256 x 144 with 56 px black pad
                           on top and bottom
  dataset clip             [16, 3, 256, 256] float32 in 0..1
  V-JEPA tokens            [B, 2048, 1408] for Giant
                           2048 = 8 time groups * 16 * 16 spatial
  Z_t                      [B, 32, 5, 5]
  Hhat_now / 1s / 1.5s / 2s  [B, 5, 5]  values 0..1
  heatmap GT               [450, 5, 5] per clip, then 5x5 slices

--------------------------------
configs/default.yaml
--------------------------------
The single settings file. Almost every number in the project is here.

Sections and what they control:

  project
    name, seed=1337

  paths
    dataset_root   relative to the BTP workspace (parent of model_trial_3)
    manifest, split_file, cache_root, checkpoint_root, logs_root,
    reports_root, visualizations_root
                   relative to model_trial_3/
    hf_cache_dir   where V-JEPA weights already live (Trial 2 cache)
    hf_cache_fallback  local hf_cache/ if the raid path is missing

  data
    30 fps, 450 frames, 1920x1080, 5x5 grid
    never_use_overlay_as_input must stay true
    min_decoded_frames=450  (shorter videos are invalid)

  preprocessing
    letterbox to 256, pad_value 0, ImageNet mean/std
    random flips/geometry OFF (collision left/right must stay left/right)
    normalize_in_backbone true  (dataset does NOT subtract mean)

  sampling
    16 frames, offsets -90..0 step 6
    horizons 30, 45, 60 frames
    stride 15
    fork_frame 365
    allow_partial_horizons true
      t_max=419 (needs 1s = t+30 <= 449); stride 15 last t is 405
      1.5s/2s past the end are masked
    ambiguous_policy mean_target
    heatmap_disagree_tol 0.02
    background_target_tolerance 0.001

  splits
    0.70 / 0.15 / 0.15 by scenario_type, at SAMPLE group level

  backbone
    facebook/vjepa2-vitg-fpc64-256
    fallback vitl
    tuning_mode frozen | lora_last6
    skip_predictor true, use_get_vision_features true

  adapter
    128 projection channels, Z 32x5x5, 2 temporal blocks
    row_weights [0.8, 0.9, 1.0, 1.1, 1.2]  (near rows matter more)

  lora
    rank 16, alpha 16, last 6 blocks

  loss
    future weights 1s=0.50, 1.5s=0.30, 2s=0.20
    now_weight 0.25, delta 0.20, FP 0.10, direction 0.05, bg 0.02

  optimizer
    AdamW, adapter_lr 0.001, lora_lr 1e-4, lora_adapter_lr 2e-4

  training
    frozen_epochs 8, lora_epochs 10, patience 4
    micro_batch_size 1, amp bfloat16, max_pair_buffer 64
    max_steps 0 means a full epoch

  cache
    cache_frames true, budget 80 GB, 2 clips in RAM LRU

  evaluation / warning / selection
    SAFE / CAUTION / STOP thresholds
    left cols 0-1, center 2, right 3-4
    checkpoint picking: recall + STOP F1, with nuisance/miss gates

--------------------------------
collision_jepa3/config.py
--------------------------------
Turns YAML into an object other files can query.

Important pieces:

  PACKAGE_ROOT     = model_trial_3/
  WORKSPACE_ROOT   = parent of that (BTP/)
  DEFAULT_CONFIG_PATH = configs/default.yaml

  Config.load(path=None, overrides=None)
    1. yaml.safe_load
    2. apply overrides like {"paths.dataset_root": "..."}
    3. validate()
    4. return Config

  Config.get("sampling.fork_frame", 365)
    Walks nested dicts. Missing key -> default.

  Config.set("training.frozen_epochs", 2)
    Scripts use this for CLI flags.

  Config.path("paths.cache_root")
    Relative cache/checkpoint/log paths resolve inside model_trial_3.
    dataset_root resolves against WORKSPACE_ROOT.

  Config.validate()
    Fails the run if:
      offsets length != 16, last offset != 0, any offset > 0
      offsets are not uniform 6-frame spacing
      not exactly 3 horizons / 3 names
      never_use_overlay_as_input is not true
      z_channels != 32 or grids != 5
      missing loss.horizon_weights
      resize_mode not letterbox or checkpoint_center_crop
      random geometric/horizontal flip is on
      ambiguous_policy not in {mean_target, collision_target, mask_ambiguous_pairs, none}

  dump_resolved(cfg)
    Adds the real absolute folders + config fingerprint to a dict
    so train logs show exactly what was used.

--------------------------------
collision_jepa3/data/manifest.py
--------------------------------
Discovers clips. Broken folders become valid=False instead of crashing.

CONSTANTS
  OUTCOME_NAMES = collision, miss_left, miss_right
  REQUIRED_FILES = preview.mp4, episode.json,
                   spatial_annotations/spatial_annotations.json

ClipRecord fields (the report card):
  clip_id                 e.g. sample_0000_jaywalker/collision/bg_00
  sample_id               sample_0000_jaywalker
  scenario_group_id       same as sample folder (split unit)
  scenario_type           jaywalker  (from _scenario_type)
  outcome_type            collision | miss_left | miss_right
  background_id           bg_00 | bg_01
  video_path, episode_json_path, heatmap_json_path
  frame_count, fps, width, height
  valid, invalid_reason
  overlay_path, annotations_path  (optional)
  lighting, biome, bg_style
  diverge_frame, hit_s, fork_frame
  outcome_group_id        sample|background   (collision vs miss mates)
  background_pair_id      sample|outcome      (bg_00 vs bg_01 mates)
  extra                   scenario, ego_mode, label_histogram, heatmap_shape

_scenario_type(sample_dir)
  sample_0006_cube_from_left -> split("_", 2) -> cube_from_left
  If the name is not sample_<id>_<rest>, return the whole name.

_read_episode(path)
  json.load of episode.json. No extra logic.

inspect_clip_dir(clip_dir, dataset_root, cfg)  — THE MAIN FUNCTION
  1. Relative path -> sample, outcome, background.
  2. Build expected file paths.
  3. If any REQUIRED_FILES missing:
       return ClipRecord(valid=False, invalid_reason="incomplete: ...")
  4. Read episode.json
       lighting = bg_lighting or environment.lighting
       biome, bg_style, diverge_frame, hit_s
       extra.scenario, ego.mode, label_histogram
       If video field is exactly "spatial_overlay.mp4": reject (label leak)
  5. probe_video(preview.mp4) -> width, height, fps, reported_frames
  6. load_heatmaps(...) expected 450 x 5 x 5
  7. If reported_frames < min_decoded_frames (450): invalid
  8. Else valid=True ClipRecord with resolved absolute paths

_invalid(...)
  Same record shape, valid=False, logs a warning.

iter_clip_dirs(dataset_root)
  For each sample_* folder:
    for each outcome folder in {collision, miss_left, miss_right}:
      for each bg_* folder:
        yield that path
  Ignores other folder names.

build_manifest(cfg, dataset_root=None)
  [inspect_clip_dir(d) for d in iter_clip_dirs]
  Logs how many valid vs invalid.

save_manifest(records, path)
  One JSON line per record. Returns 16-char sha256 fingerprint.

load_manifest(path)
  Rebuilds ClipRecord(**dict) per line.

manifest_stats(records)
  Counters of outcomes, backgrounds, scenarios, biomes, lighting,
  invalid reasons, number of groups.

valid_clips(records)
  Filter valid=True.

collision_jepa3/data/preprocessing.py
--------------------------------
RGB resize/pad. Does NOT subtract ImageNet mean (backbone does that).

  PreprocessSignature  frozen dataclass of resize_mode, size, pad, mean, std
  signature_from_cfg(cfg)

  letterbox_rgb(frame, size=256, pad_value=0)

  uint8_to_nchw01

collision_jepa3/data/sampling.py
--------------------------------
Locked 16-frame / 3-second contract. Do not change offsets casually;
config.validate() will refuse non-uniform spacing.

  FRAME_OFFSETS = -90,-84,...,-6,0     (16 numbers, 6 apart)
  HORIZONS_FRAMES = 30, 45, 60         (1s, 1.5s, 2s at 30 fps)

  input_indices(t)
    [t-90, t-84, ..., t]
    ERROR if any index > t (future leak)
    ERROR if last != t

  target_indices(t)
    {now: t, 1s: t+30, 1_5s: t+45, 2s: t+60}

  available_horizons(t, n_frames=450)
    True/False per name including "now"

  valid_anchor_range(n_frames=450)
    t_min = 90  (need 3s of history)
    t_max = 419 if allow_partial_horizons (need 1s = t+30 <= 449)
    t_max = 389 if all three futures required (t+60 <= 449)

  iter_anchors(n_frames, stride=15)
    [90, 105, 120, ..., 405]  with default partial=True
    About 22 anchors per clip

Example at t=330:
  inputs  240,246,...,330
  now 330, 1s 360, 1.5s 375, 2s 390
  fork 365  => 1s still pre-fork, 1.5s and 2s post-fork

--------------------------------
collision_jepa3/data/splits.py
--------------------------------
Splits SAMPLE GROUPS, never individual clips.

  _hash_order(names, seed)
    Stable shuffle using sha256(seed:name). Same seed => same split.

  _quota(n, 0.7, 0.15, 0.15)
    How many groups go to train/val/test.
    Tiny n: 1 group -> all train; 2 groups -> 1 train 1 val.

  split_groups(records, seed, fractions, stratify_by="scenario_type")
    1. Keep valid clips only.
    2. One group id per sample folder.
    3. Bucket groups by scenario_type (jaywalker, cube_from_left, ...).
    4. For each type with >= 3 groups, cut 70/15/15.
    5. Types with 1-2 groups go to a leftover pool, then split that pool
       so rare types can still appear in val/test.
    6. If val is still empty, steal one group from train. Same for test.
    7. ERROR if any group is in two splits (leakage) or left unassigned.
    Return {"train": [sample_...], "val": [...], "test": [...]}

  save_splits / load_splits
    JSON with {"splits": {...}, extra metadata}

  clip_split_map
    clip_id -> "train"|"val"|"test"

WHY GROUPS: if collision of sample_0000 is train and miss of sample_0000
is val, the model would see the same 3-second prefix in both splits.

--------------------------------
collision_jepa3/data/pairing.py
--------------------------------
Two pairing axes + the collision-target rewrite.

  heatmaps_disagree(a, b, tol=0.02)
    True if max |a-b| > tol  (any cell)

  outcome_mates(records)
    dict[outcome_group_id] -> [ClipRecords]
    outcome_group_id = "sample_0000_jaywalker|bg_00"
    So collision/bg_00 and miss_left/bg_00 are mates.

  background_mates(records)
    dict[background_pair_id] -> [ClipRecords]
    background_pair_id = "sample_0000_jaywalker|collision"
    So collision/bg_00 and collision/bg_01 are mates.

  compute_ambiguity_table(...)
    Returns {(clip_id, t): {"1s": bool, "1_5s": bool, "2s": bool}}

    Steps:
      1. All valid (clip, t) start as False.
      2. If mask_ambiguous is False, return that (all False).
      3. For each outcome group with a collision AND at least one miss:
           for each t:
             if t >= fork: skip (history already shows the branch)
             for each horizon:
               if collision heatmap at t+h disagrees with miss heatmap:
                 mark BOTH clips True on that horizon

    Example t=330, fork=365:
      1s=360 still same -> False
      2s=390 already split -> True

  collision_clip_by_outcome_group
    "sample|bg_00" -> that group's collision clip_id

  apply_mean_future_targets(targets, rec, t, amb, heatmaps, ...)
    For each horizon with amb[name]=True and the frame still exists:
      replace h_1s / h_1_5s / h_2s with the cell-wise AVERAGE of
      collision and miss heatmaps at that frame
    Returns (new_targets, set_of_replaced_names)

    Miss clip at t=330, 2s:
      original miss heatmap at 390 may be all zeros, collision ~0.96
      after rewrite: (0.96 + 0.0) / 2 = 0.48 in that cell

    Collision clip: also gets that same average, not its raw map.
    t=375 (after fork): amb all False, nothing replaced.

  background_pair_valid(rec_a, rec_b, hm_a, hm_b, t, horizons, tol)
    True only if:
      same background_pair_id
      different clip_id
      same outcome_type
      same scenario_group_id
      heatmaps at now and available futures agree within tol
    Used to decide whether Z_t of bg_00 and bg_01 should match.

  load_cached_frames(..., mmap=True)
    np.load mmap_mode="r" so 450x256x256x3 is not all copied into RAM.

  TokenCache
    Optional encoder-token cache (cache.cache_encoder_tokens is false
    by default). Keys by clip_id + anchor. Invalid if backbone/LoRA/
    preprocess fingerprint changes. Not used in the default train loop.

collision_jepa3/data/dataset.py

PyTorch Dataset. One item = one clip at one time t.

TeacherDataset.__init__
  1. Keep records whose scenario_group_id is in this split.
  2. Compute anchors with iter_anchors (stride depends on split).
  3. load_heatmaps for every clip into RAM (450x5x5 is small).
  4. compute_ambiguity_table (always, if policy is mean_target,

  7. LRU of decoded clips (default 2) to avoid re-reading npy

_horizon_masked(name, amb, avail, replaced)
  True  -> skip this horizon in the loss
  Rules:
    future frame missing            -> True (must skip)
    this horizon was rewritten to
      the mean heatmap              -> False (TRAIN on it)

__getitem__(i)

  6. Return a dict (see keys below)

  _resolve_hf_cache

  DummyVJEPA2Backbone

--------------------------------
collision_jepa3/models/lora.py
--------------------------------
  LoRALinear
    Frozen original Linear.
    lora_A [rank, in], lora_B [out, rank]
    y = W x + (alpha/rank) * B(A(x))
    A kaiming init, B zeros (starts as no change).

  apply_lora_to_last_blocks(model, last_n=6, rank=16, alpha=16)
    Finds encoder.layer / blocks / layers, wraps Linear in the last N.
    Returns how many Linears were wrapped.

  lora_parameters(model)  all lora_A / lora_B tensors

--------------------------------
collision_jepa3/models/spatial_adapter.py
--------------------------------
Tokens -> Z_t [B, 32, 5, 5]

  TemporalResidualBlock
    Depthwise conv along TIME only (kernel 3, optional dilation),
    then 1x1, GroupNorm, GELU, residual add.

  SpatialTemporalAdapter.forward(tokens [B,N,C])
    1. tokens_to_grid
         MUST have N == T'*S*S exactly. Refuses to slice/pad.
         -> [B, T', C, S, S]   Giant: [B,8,1408,16,16]
    2. spatial_proj per time group: 1x1 then 3x3 -> 128 channels
    3. temporal residual blocks on [B,128,T',16,16]
    4. mix mean-over-time with last time group
    5. adaptive_avg_pool2d to 5x5
    6. 1x1 bottleneck to 32 channels
    7. LayerNorm over channels
    8. Z_t [B,32,5,5]  or RuntimeError if shape is wrong

--------------------------------
collision_jepa3/models/heatmap_decoder.py
--------------------------------
  HeatmapDecoder(Z_t) -> Hhat_now [B,5,5] via 1x1, 3x3, 1x1, sigmoid

  HeatmapDelta(z_residual) -> Delta [B,5,5] via same convs, tanh (-1..1)

  copy_residual_future(h_now, delta)
    clamp( stop_gradient(h_now) + delta, 0, 1)
    Future map = current map plus a learned change.
    stop_gradient so the future head does not fight the now head
    by pushing Hhat_now around.

--------------------------------
collision_jepa3/models/residual_predictor.py
--------------------------------
  Zhat_h = Z_t + convs(Z_t)
  One ResidualPredictor per horizon (1s, 1.5s, 2s).
  Dilated 3x3 helps the 5x5 grid see left vs right.

--------------------------------
collision_jepa3/models/teacher.py
--------------------------------
The full teacher.

  CollisionTeacher3(cfg, dummy_backbone=False)
    backbone + SpatialTemporalAdapter + HeatmapDecoder
    + ModuleDict of ResidualPredictor and HeatmapDelta (one each per horizon)

  train(mode=True)
    Calls super().train but FORCES backbone.eval()
    so dropout/BN in Giant stay frozen.

  forward(clip=None, tokens=None)
    encode -> Z_t
    _heads:
      Hhat_now = decoder(Z_t)
      for name in 1s, 1_5s, 2s:
        Zhat = predictor[name](Z_t)
        Delta = delta_heads[name](Zhat - Z_t)
        Hhat  = copy_residual_future(Hhat_now, Delta)
    Returns dict with Z_t, Hhat_now, Hhat_*, Delta_*, Zhat_*

  adapter_parameters()  adapter+decoder+predictors+delta_heads
  lora_parameters()
  enable_lora()         wrap last 6 blocks, maybe gradient checkpointing
  parameter_audit()     counts total/trainable/frozen/adapter/lora

PART 8. LOSSES  (collision_jepa3/losses/)
================================================================

--------------------------------
collision_jepa3/losses/__init__.py
--------------------------------
Exports TeacherLoss, TeacherLossOutput, target_weighted_mse,
false_positive_penalty.

--------------------------------
collision_jepa3/losses/heatmap.py
--------------------------------
  row_priority_weights([0.8,0.9,1.0,1.1,1.2])
    Normalize so mean is 1. Bottom (near) rows > 1, top (far) < 1.

  cell_threat_weights(target)
    w_ij = 0.05 + 4.0 * H_ij^2     then divide by mean
    Dangerous cells pull the loss harder. Safe cells still count a little
    (the floor) so the model cannot ignore them.

  target_weighted_mse(pred, target, sample_mask=...)
    Weighted MSE. Weights come from TARGET, never from the prediction
    (so the model cannot hide by predicting zeros).
    sample_mask False -> that batch item is dropped.
    If the whole batch is masked, returns 0.

  false_positive_penalty
    On cells where GT < 0.05 (safe):
      penalize relu(pred - 0.10)^2
    Stops the model from painting danger everywhere to get recall.

--------------------------------
collision_jepa3/losses/residual.py
--------------------------------
  residual_target = clamp(H_future - stopgrad(Hhat_now), -1, 1)
  delta_loss compares Delta_hat to that, with the same weighted MSE,
  mixed with extra weight on the residual magnitude
  (delta_residual_mix=0.5).

--------------------------------
collision_jepa3/losses/direction.py
--------------------------------
  Columns 0-1 LEFT, 2 CENTER, 3-4 RIGHT.
  Score = temperature * logsumexp(row_weighted cells / T)
  Softmax over the three directions, cross-entropy vs GT direction
  (only when GT peak is above threat_threshold 0.42).

  Teaches "danger is on the left" even if exact cells are a bit off.

--------------------------------
collision_jepa3/losses/background_consistency.py
--------------------------------
  Z_a, Z_b : [B,32,5,5]
  Per cell, cosine of the 32-D vector.
  Loss = mean(1 - cos)
  "Same collision on two streets should have similar Z_t."

--------------------------------
collision_jepa3/losses/composite.py
--------------------------------
TeacherLoss.__call__(model_out, batch, z_bg_pair=None)

  Always:
    L_now = weighted MSE(Hhat_now, h_now)     NEVER uses amb mask

  For each of 1s, 1_5s, 2s:
    valid = NOT amb_*
    L_h, L_delta, L_FP, L_dir  (all masked by valid)
    multiply by horizon_weights (0.50 / 0.30 / 0.20)

  L_bg if z_bg_pair provided, else 0

  L_total =
      L_future
    + 0.25 * L_now
    + 0.20 * L_delta
    + 0.10 * L_FP
    + 0.05 * L_dir
    + 0.02 * L_bg

  Returns TeacherLossOutput(total, terms dict) for logging.

Under mean_target, amb_* is False on rewritten futures, so those
horizons ARE in L_future, with the collision/miss average as h_1s/h_1_5s/h_2s.

    model.train(); backbone.eval()

PART 13. ONE TRAINING STEP, SLOW MOTION
================================================================

Index i might be:
  clip = sample_0000_jaywalker/miss_left/bg_00
  t    = 330

1. dataset loads frames 240..330 of preview.mp4 (from cache if present),
   letterboxed to 16 x 3 x 256 x 256, values 0..1.

2. Heatmaps:
   h_now  = miss map at 330   (same as collision; still pre-fork)
   h_1s   = miss map at 360   (still same as collision)
   h_1_5s = miss map at 375   (already split)
   h_2s   = miss map at 390   (miss is ~zeros, collision has ~0.96)

3. ambiguity table says 1_5s and 2s are True (disagreed, t < 365).

4. policy mean_target:
   h_1_5s and h_2s are REPLACED with the average of collision and miss
   maps at 375 and 390.
   amb_1_5s = amb_2s = False  (we will train)
   amb_1s stays False anyway

5. Batch hits GPU. CollisionTeacher3:
   backbone normalizes ImageNet, Giant tokens [1,2048,1408]
   adapter -> Z_t [1,32,5,5]
   decoder -> Hhat_now [1,5,5]
   three residual heads -> Hhat_1s, Hhat_1_5s, Hhat_2s

6. TeacherLoss:
   L_now vs miss/collision-identical now map
   L_1s vs map at 360
   L_1_5s and L_2s vs COLLISION maps (the rewritten targets)
   plus delta, FP, direction
   maybe L_bg if miss_left/bg_01 at t=330 was recently in PairBuffer
   wait: background pair is same OUTCOME different BG, so mate would
   be miss_left/bg_01, not the collision clip.

7. Backward through adapter/heads (and LoRA in phase B), not Giant
   in phase A.

8. Optimizer step. Checkpoint if this epoch's val selection is best.
